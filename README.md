# Sacred Tree: Summoning Gelora
gelora-xr.xyz

Sacred Tree is a cosmotechnical XR ritual rooted in Korean sacred tree traditions and five-directional color cosmology. Participants summon Gelora, hybrid beings reanimated from fallen flowers, by reaching down to tap NFC-activated portals. From pixel to voxel, each embodied gesture generates co-authorship. A generative soundscape of pentatonic harmonies morphs in real-time, breathing with participant interaction and augmented creatures, Gelora. Exhibited at HOZO Tết City Festival in Ho Chi Minh City, the shared ritual crossed cultures, finding relational ground through mediated touch.
